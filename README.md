📚 Student Management System (Java Swing)

A simple desktop-based Student Management System built using Java Swing and OOP concepts.
It allows users to manage student records with an interactive GUI and table-based display.


---

🚀 Features

➕ Add new student (ID, Name, Marks)

❌ Delete student by ID

🔍 Search student by ID

✏️ Update student details

📊 Display all students using JTable

🧠 Built using Java OOP concepts (Encapsulation, Classes, Objects)

🖥️ User-friendly Swing GUI
